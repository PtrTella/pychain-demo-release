# pychain-demo-release

A small package without dependencies, written for one experiment of the master's
thesis "PyChain" (University of Bologna, 2026).

The experiment publishes this repository with the PyChain client, lets the client ask
Software Heritage to visit it, waits until the source tree is in the archive, removes
the release archive and its metadata from the local IPFS node, and rebuilds both from
the archived tree. Before this repository was made public, its tree was not held by
Software Heritage.

The package has no other purpose.
